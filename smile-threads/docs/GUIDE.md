# スマイル共済 Threads集客・相談管理 — かんたん設定ガイド

## 0. これは何？
Threadsで出会った人を、LINEまたは予約ページから個別相談につなげるための管理画面です。スマホのブラウザで使えます。
**できること**: 投稿案づくり→確認→予約公開 / コメント対応 / DM返信案づくり(手入力) / LINE自動応答 / 相談予約 / 問い合わせ管理 / 数字の確認 / フォロー覚え書き
**できないこと**: ThreadsのDM自動送受信、自動フォロー(公式に確認できないため作っていません)

## 1. 起動(まず自分のパソコンで試す)
1. Node.js 22.13以上をインストール(https://nodejs.org)
2. このフォルダ(`smile-threads`)で:
   ```
   npm run setup     # パスワードを決める(12文字以上)。.env が作られます
   npm run seed      # (任意)デモデータを入れる
   npm start         # 起動 → http://localhost:3000
   ```
3. ブラウザで開き、パスワードでログイン。最初は **すべて「テストモード」**で、実際の投稿・送信は一切行われません。
4. テスト: `npm test`

## 2. 最初の投稿から相談受付までの流れ
1. **設定 → 1.商品情報と公式資料**: 正式名称・保障内容・掛金などを、公式資料を見て入力。「所属先ルールを確認した」にチェック。
2. **投稿 → 下書きを作る**: テーマを選ぶ。書き換えて、黄色い注意(断定・数値・体験談など)を確認。「確認しました」にチェック→**承認**。
3. 日時を決めて**予約**(Threads未連携の間は「連携待ち」表示。投稿されたようには見せません)。
4. Threadsのプロフィールに、LINE友だち追加URL(または予約ページURL)を載せる。
5. 友だち追加されると、LINEが自動であいさつ+4つのメニューを出します。**確認済みにした文面だけ**自動送信。分からない質問は「わっちへ引き継ぎ」。
6. 「個別相談を予約したい」→予約ページ→日時と方法を選ぶ→わっちに通知、本人に確認メッセージ。
7. **相談 → 問い合わせ**で状況を管理(未対応→返信待ち→相談予定→対応済み→対応終了)。
8. ThreadsのDMが来たら、**返信 → ThreadsのDM**に貼り付け→返信案→コピー→Threadsで自分で送信。

## 3. 本番につなぐ(あなたが用意するもの)
| 用意するもの | 内容 | 料金などの確認先 |
|---|---|---|
| **公開サーバー(https)** | LINEのWebhookは外から届く必要があります。Render / Railway / Fly.io / VPS など、Node常時起動できるもの。`data/` フォルダ(DB)を消えない場所に保存すること | 各サービスの料金ページ(無料枠は停止・消去される場合あり) |
| Meta開発者アカウント+Threads API | アプリ作成、権限の取得、アクセストークンとユーザーID | developers.facebook.com の Threads ドキュメント |
| LINE公式アカウント+Messaging API | チャネルシークレット/アクセストークン、Webhook URL設定、「応答メッセージ」をオフ | LINE Developers / 料金ページ |
| (任意)AIのAPIキー | **ChatGPT等の有料プランとAPI料金は別**。すでにお持ちならそれを、なければ「使わない」でOK | 各社の公式料金ページ |
| (任意)Googleカレンダー | サービスアカウント+カレンダー共有(未検証機能) | Google Cloud |
| 正式な商品資料 | 正式名称・運営元・保障・掛金・加入条件・所属先の募集ルール | 所属先 |

公開時は `.env` に `PUBLIC_BASE_URL=https://あなたのURL` と `COOKIE_SECURE=1` を設定し、`ADMIN_PASSWORD_HASH` と `APP_SECRET` は `npm run setup` で作ったものを使います(サービスの環境変数に設定すれば `.env` ファイルは不要)。

接続手順は、設定画面の「❓」を開くと各画面に書いてあります。
**本番に切り替えるときは、確認の入力が必要**です(誤送信防止)。

## 4. 安全のための仕組み
- パスワードはハッシュ化、5回失敗で15分ロック、ログインは12時間、「全端末ログアウト」あり
- APIキー・トークンは**暗号化して保存**し、画面・ログには出しません(「設定済み」とだけ表示)
- LINE Webhookは**署名検証に成功したものだけ**処理
- **すべて一時停止**ボタン(ホーム)で、自動投稿・自動返信・LINE自動応答を止められます
- 二重投稿防止(1投稿につき公開処理は1回だけ)、二重返信防止、二重予約防止
- 承認後に本文を直すと承認が外れます
- 保存期間(初期365日)を過ぎたログは毎日自動削除。個別の問い合わせは画面から完全削除可
- 病歴・個人情報の記入を促す文面は登録・承認できません。LINEの商品回答は、確認済み文面のみ

## 5. こまったとき
- 「連携待ち」→ 設定でトークンを保存し、モードを本番に
- 投稿が「エラー」→ 投稿を開くとエラー内容が出ます。直して再度承認→予約。**Threadsで実際に投稿されていないか確認してから**再投稿してください
- サーバーを再起動しても予約は残ります(起動中に時刻が来た投稿だけ公開されます)
